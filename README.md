# FlowDesk Landing Page

## Description
FlowDesk is a fictional SaaS productivity and team management platform. This project was built using only HTML5 to demonstrate semantic HTML structure and webpage organization.

## Features
- Header with Navigation Menu
- Hero Section
- Features Section
- How It Works Section
- Pricing Plans
- FAQ Section
- About Section
- Contact Form
- Footer

## Technologies Used
- HTML5

## Purpose
The purpose of this project is to practice semantic HTML, forms, links, images, lists, tables, and proper webpage structure without using CSS or JavaScript.
